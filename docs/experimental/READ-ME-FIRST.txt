EXPERIMENTAL VERSION OF THE CBST SEEDLOT SELECTION TOOL
========================================================

This folder is a self-contained copy of the seedlot map for experimental
changes. Edits made inside this folder do NOT affect the official version
at https://bcgov.github.io/nr-seedtransfer-map/

LIVE URL FOR THIS VERSION
-------------------------
https://bcgov.github.io/nr-seedtransfer-map/experimental/index.html

WHAT'S IN THIS FOLDER
---------------------
  index.html       The page (copy of the original)
  css/             Stylesheets (copy of the original)
  scripts/         JavaScript (copy of the original — edit these freely)
  Version_7_0/     Data folder (currently EMPTY — upload JSON files here)

HOW TO MAKE A CHANGE
--------------------
  1. Pull the latest from main.
  2. Edit any file inside this experimental/ folder.
  3. Upload data files into Version_7_0/ as needed.
  4. Commit, push to a feature branch, and open a Pull Request. Once approved and merged, GitHub Actions will deploy.
  5. Wait 30-60 seconds for GitHub Pages to deploy.
  6. Refresh the experimental URL above to see your changes.

NOTES
-----
  * The page will not render correctly until you upload data files
    into Version_7_0/. The official data folder lives at
    /docs/Version_7_0/ if you need to see what filenames are expected.
  * Do not edit anything OUTSIDE this experimental/ folder unless you
    intend to change the official version.
  * The yellow banner at the top of the experimental page is what
    distinguishes it from the official tool. Leave it in place so
    visitors don't confuse the two.
